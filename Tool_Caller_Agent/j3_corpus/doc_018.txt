### SOC Runbook Excerpt: Handling a DDoS Attack Against Public-Facing Web Infrastructure

#### Objective:
This runbook is designed to provide guidance on handling a Distributed Denial of Service (DDoS) attack targeting the public-facing web infrastructure of AcmeTech Inc., specifically their website hosted at `www.acmetech.com`. The objective is to mitigate the attack, ensure the availability and integrity of critical services, and minimize any potential harm.

#### Steps:

1. **Initial Detection:**
   - At 2023-10-15T14:00Z, an alert was generated by the Intrusion Detection System (IDS) indicating a surge in traffic from multiple IP addresses targeting `www.acmetech.com`. The IDS flagged a potential DDoS attack.
   
2. **Traffic Analysis:**
   - Use NetFlow data to gather detailed information about the attack. Analyze the traffic patterns to identify the source of the attack and the type of attack vectors (e.g., volumetric, application-layer).
   - Execute `sudo nethogs` on network devices to monitor real-time bandwidth usage.
   - Generate a report using tools like `tcpdump` or Wireshark for packet analysis.

3. **Engage Upstream Provider:**
   - At 2023-10-15T14:30Z, contact the upstream internet service provider (ISP) to inform them of the DDoS attack.
   - Request their cooperation in filtering traffic from known malicious sources and implementing rate limiting on specific IP addresses or IP ranges. 
   - Provide them with a list of suspicious IPs identified by the IDS for immediate blocking.

4. **Deploy Web Application Firewall (WAF):**
   - At 2023-10-15T15:00Z, update the WAF rules to include the following:
     - Block all traffic from IP addresses previously identified as malicious.
     - Implement rate limiting on common HTTP methods such as GET and POST with thresholds set at 100 requests per second.
     - Configure CAPTCHA challenges for suspicious user sessions.
   - Test the updated WAF rules in a staging environment before deployment to ensure no false positives.

5. **Monitor and Report:**
   - Continuously monitor network traffic using tools like `ntopng` or `Zeek`.
   - Use SIEM tools (e.g., Splunk) to correlate events across multiple sources.
   - Document all actions taken, including timestamps, affected systems, and resolution strategies.

6. **Post-Mitigation Review:**
   - At 2023-10-15T20:00Z, conduct a post-mortem review of the incident to identify any weaknesses in current security measures.
   - Update the incident response plan based on lessons learned and improve WAF rules as necessary.

By following these steps, AcmeTech Inc. can effectively manage and mitigate DDoS attacks, ensuring the resilience and availability of its public-facing web infrastructure.
