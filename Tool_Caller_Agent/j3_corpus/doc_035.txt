### IOC Intelligence Entry: Weaponized Office Document (CVE-2024-XXXX)

**Summary:** A recently discovered weaponized Office document with a CVE identifier (CVE-2024-XXXX) was observed to be distributed via spear-phishing attacks targeting specific individuals in the finance sector. The document leverages macros to execute a payload, which then establishes a backdoor on the compromised system.

**Date of Discovery:** March 15, 2024

**Victim Profile:** Finance industry professionals within large multinational corporations.

**Attack Vector:** Spear-phishing emails containing malicious Office documents.

**Indicators of Compromise (IOCs):**

- **Email Subject:** "Urgent: Q4 Financial Report – Update Required"
- **Email Body:** The email body is crafted to mimic internal communications and includes a link or attachment that appears legitimate.
- **Attachment Name:** `Q4_Financial_Report.docx`
- **Macro Content Summary:**
  - The document contains a macro named `AutoExec`, which when enabled, opens another hidden file (`config.xml`) in the `%TEMP%` directory.
  - The `config.xml` file contains encoded URLs pointing to a command-and-control (C2) server.

**Payload Delivery Chain:**

1. **Initial Engagement:** A spear-phishing email is sent to targeted individuals within the finance department, posing as an urgent update for Q4 financial reports.
2. **Macro Execution:** When the user opens `Q4_Financial_Report.docx`, the macro `AutoExec` runs and executes without any immediate visual alerts (due to trusted environment settings).
3. **File Extraction:** The macro extracts a hidden file named `config.xml` from the document into the `%TEMP%` directory.
4. **C2 Interaction:** The `config.xml` contains encoded URLs that instruct the payload to connect back to the C2 server for further instructions and updates.

**YARA Rule:**

```yara
rule WeaponizedOfficeDocumentCVE_2024XXXX : OfficeDocument_SpearPhishing {
    meta:
        description = "YARA rule for identifying weaponized Office documents associated with CVE-2024-XXXX."
        date = "2024-03-15"
        author = "Alibaba Cloud Qwen"
        company = "Qwen"

    strings:
        $macro_name = "AutoExec" fullword ascii
        $hidden_file = "config.xml" fullword ascii
        $encoded_url_pattern = { 48 69 2F 53 70 65 63 2E 63 6F 6D 0A } // Example pattern for URL encoding

    condition:
        all of ($macro_name) and any of ($hidden_file, $encoded_url_pattern)
}
```

**Additional Notes:**
- The document employs techniques to evade basic security tools by using obfuscation in the macro code.
- The C2 server is hosted on a domain with a legitimate-looking name but has been identified as malicious through network traffic analysis.

This intelligence entry highlights the sophisticated nature of this attack, emphasizing the importance of user education and robust anti-malware solutions.
