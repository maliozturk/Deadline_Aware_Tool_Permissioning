### SOC Runbook Excerpt: Unauthorized Lateral Movement Investigation

**Incident ID:** SOC-2023-09-15-001  
**Detected Date:** September 15, 2023  
**Time of Detection:** 14:30 UTC  
**Device/Network:** Internal Network Segment 172.16.10.0/24  

---

#### Incident Summary
An unauthorized lateral movement has been detected on the internal network segment 172.16.10.0/24, specifically from host **"HR-SERVER-01"** (IP: 172.16.10.5) to host **"SALES-SERVER-01"** (IP: 172.16.10.8). The initial access point was via a compromised account, and subsequent lateral movement was detected through suspicious network traffic patterns.

#### Objectives
1. Determine the nature of the compromise.
2. Identify any further spread to other hosts.
3. Implement necessary security measures to prevent future unauthorized access.
4. Document findings for incident response reporting.

---

### Investigation Steps

**Step 1: Immediate Action**
- **Reset Compromised Credentials:** Promptly reset the credentials used by the attacker on both "HR-SERVER-01" and "SALES-SERVER-01."
    - Use the following command to change the password for user **"admin"**: `passwd admin`
    - Verify that the new password is set correctly: `whoami`

**Step 2: Affected Host Enumeration**
- **Enumerate Connected Devices:** Utilize network scanning tools like Nmap or Nessus to identify any additional hosts potentially affected by this lateral movement.
    ```bash
    nmap -sP 172.16.10.0/24
    ```

**Step 3: Forensic Image Collection**
- **Collect System and Network Logs:** Ensure that all relevant logs are collected from the compromised hosts, as well as any network devices they may have interacted with.
    - On "HR-SERVER-01": `sudo journalctl --vacuum-time=2d`
    - On "SALES-SERVER-01": `sudo journalctl --vacuum-time=2d`

- **Create Forensic Images:** Use tools like Foremost or volatility to create forensic images of the hard drives.
    ```bash
    dd if=/dev/sda of=hr_server_01_image.img bs=4M status=progress
    ```

**Step 4: Analyze Logs and Forensic Data**
- **Analyze Network Traffic:** Review network traffic logs from "HR-SERVER-01" to identify any additional hosts or systems that may have been accessed.
- **Examine System Files:** Check for signs of malicious activity in key system files using tools like `grep` or `strings`.
    ```bash
    grep -r "suspicious_string" /var/log/*
    ```

**Step 5: Incident Reporting and Documentation**
- Document all findings, actions taken, and recommendations for mitigating future incidents.
- Report to the security team and relevant stakeholders.

---

### Conclusion
The investigation of unauthorized lateral movement is critical in understanding the extent of the breach and implementing effective remediation measures. By following these steps, we can contain the damage, identify potential vulnerabilities, and enhance our network's resilience against such attacks.
