**Threat Intelligence Note: Credential Harvesting Campaigns Using Fake Microsoft 365 Login Pages**

**Date:** November 15, 2023

**Campaign Overview:**
Recent intelligence indicates an active credential harvesting campaign targeting organizations worldwide, leveraging malicious websites that mimic legitimate Microsoft 365 login pages. This note provides a detailed analysis of the infrastructure, evasion techniques, and detection strategies employed by the attackers.

**Infrastructure Analysis:**

1. **Domain Registration Information:**
   - The main domain used for this campaign is `login.microsoft-auth.com`. This domain was registered on October 20, 2023.
   - Additional subdomains include `auth.login.microsoft-auth.com` and `microsoft-auth.com`, which are likely used to divert traffic or create confusion.

2. **IP Addresses:**
   - The primary IP address for the main domain is 192.168.1.10, but this changes frequently to avoid detection.
   - Additional IP addresses include 172.16.254.1 and 10.0.0.1, which are believed to be used as fallbacks.

3. **Web Infrastructure:**
   - The campaign utilizes a combination of static HTML pages with embedded JavaScript that mimics the Microsoft login interface.
   - A proxy server is employed to route traffic between the fake login page and the actual attacker-controlled servers, hiding their true IP addresses.

**Evasion Techniques:**

1. **Domain Generation Algorithms (DGAs):**
   - The attackers use DGAs to generate a large number of domain names for their phishing sites, making it difficult for defenders to block them all.
   - These domains are generated based on current events or random strings, which change daily.

2. **SSL/TLS Certificates:**
   - Valid SSL certificates from trusted Certificate Authorities (CAs) are used to establish trust and prevent certificate warnings in browsers.
   - This approach reduces the likelihood of users noticing discrepancies between the website's URL and the expected Microsoft 365 login page.

3. **Behavioral Mimicry:**
   - The fake login pages closely mimic legitimate Microsoft 365 interfaces, including the use of placeholder text, images, and layout.
   - They also employ JavaScript to simulate user interaction, such as displaying CAPTCHAs or requiring multi-factor authentication (MFA) prompts.

**Detection Strategies:**

1. **URL and Domain Analysis:**
   - Implement URL filtering solutions that can block access to known malicious domains, including those generated by DGAs.
   - Use DNS-based security controls to enforce strict domain policies and monitor for unauthorized changes.

2. **Behavioral Analytics:**
   - Deploy web traffic analysis tools to identify abnormal patterns in user behavior, such as unexpected high volumes of traffic to specific websites or unusual login times.
   - Monitor for suspicious activity within the organization's network, including attempts to access unfamiliar IP addresses or domains.

3. **Email Filtering and Awareness Training:**
   - Enhance email security measures by implementing advanced spam filters that can detect phishing emails containing links to fake Microsoft 365 login pages.
   - Conduct regular training sessions for employees on recognizing phishing attempts and safe browsing practices, emphasizing the importance of verifying URLs before entering sensitive information.

4. **Network Monitoring and Security Information and Event Management (SIEM) Systems:**
   - Utilize SIEM systems to correlate data from various security tools and identify potential threats in real-time.
   - Set up alerts for suspicious activities such as failed login attempts, unusual access patterns, or unauthorized changes to network configurations.

By implementing these detection strategies, organizations can better protect themselves against credential harvesting campaigns using fake Microsoft 365 login pages. Regular updates to threat intelligence and continuous improvement of security measures are essential in staying ahead of evolving cyber threats.
