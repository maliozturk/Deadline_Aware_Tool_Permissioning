### SOC Runbook Excerpt: Responding to a Ransomware Infection on File Server

#### **Incident Summary**
On March 15, 2023, at approximately 14:47 UTC, the Security Information and Event Management (SIEM) system detected unusual activity from a file server with hostname `FILESRV-01` located in the North America region. The SIEM log indicated that files on the server were being encrypted, which is consistent with ransomware behavior.

#### **Incident Response Team**
- Lead: John Doe
- Analysts: Jane Smith and Mike Johnson
- Incident Communicator: Sarah Lee

#### **Isolation Steps**

1. **Immediate Isolation**: At 14:50 UTC, the file server `FILESRV-01` was isolated from the network to prevent further spread of the ransomware.
   - Network isolation achieved by modifying the server’s firewall rules and disconnecting it from the primary network.

2. **Containment Measures**:
   - Suspended all scheduled backups on `FILESRV-01`.
   - Verified that no other systems were compromised through a thorough network scan using Nmap at 15:00 UTC.
   - Ensured that only necessary personnel had access to the isolated server.

#### **Backup Verification**

1. **Verify Latest Backups**: At 16:00 UTC, verified the integrity and availability of backups for `FILESRV-01` from February 28, 2023.
   - Backup location: `/backups/FILESRV-01_Feb28_2023`
   - Backups were confirmed to be complete and consistent with previous runs.

2. **Test Restorable Files**: Selected a sample of critical files from the backup for restoration tests at 16:30 UTC.
   - Sample included documents, spreadsheets, and configuration files.
   - Restoration process was successful without any corruption or data loss.

#### **Negotiation Policy Reference**

Given that `FILESRV-01` contains sensitive financial reports, the negotiation policy referenced in this scenario emphasizes minimal communication with the attackers. The policy states:

- **Do not initiate contact** unless specifically requested by law enforcement.
- **Respond with generic, non-specific information**: Avoid providing detailed system or network information to prevent further compromise.

#### **Recovery Procedure Outline**

1. **Restore Files from Backup**: At 17:00 UTC, restored the most recent clean backup of `FILESRV-01` onto a newly created virtual machine (VM) in a separate environment.
   - VM host: `VMHOST-NETWORK`
   - IP Address: 192.168.10.3

2. **Verify Recovery**: Once the restoration is complete, verified that all critical data has been restored accurately and without corruption.

3. **Thorough System Scan**:
   - Conducted a full system scan using EICAR (a non-malicious test file for antivirus software) at 18:00 UTC.
   - Ensured no traces of ransomware remain, and all systems are clean.

4. **Gradual Reintegration**: Once verified, the restored VM was gradually reintegrated into the production network under close monitoring to ensure no further issues arise.

5. **Post-Incident Review**:
   - Conducted a post-incident review on March 20, 2023.
   - Identified gaps in initial detection and response procedures.
   - Enhanced incident response plan to include more frequent monitoring of critical systems.

This runbook excerpt provides a structured approach for responding to a ransomware infection, ensuring the system is isolated, backed up, and restored while adhering to strict security policies.
