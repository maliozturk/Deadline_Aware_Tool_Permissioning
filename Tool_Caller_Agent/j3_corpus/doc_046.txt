**Threat Intelligence Note: Credential Harvesting Campaign Using Fake Microsoft 365 Login Pages**

**Date:** October 14, 2023

**Threat Actor Profile:**
This threat actor is utilizing a sophisticated credential harvesting campaign that leverages phishing techniques to trick users into entering their login credentials on fake Microsoft 365 (M365) webpages. The actors have been observed using various evasion tactics and have established a robust infrastructure to facilitate the compromise of corporate networks.

**Infrastructure Analysis:**
The threat actor employs a multi-layered infrastructure that includes multiple domain names, IP addresses, and malicious URLs designed to mimic legitimate M365 login pages. Key components include:

1. **Domain Names:** 
   - `microsoftlogin-secure.com`
   - `office365-authentication.net`

2. **IP Addresses:**
   - 93.184.216.34 (used as a C&C server)
   - 34.75.123.21 (used for phishing page hosting)

3. **Malicious URLs:**
   - `https://microsoftlogin-secure.com/login`
   - `http://office365-authentication.net/auth`

The infrastructure is designed to be resilient, with a domain fronting technique used to mask the true IP address and domain name of the phishing server. This makes it difficult for security tools to identify and block the malicious activities.

**Evasion Techniques:**
The threat actors employ several evasion techniques to avoid detection:

1. **Domain Fronting:** The phishing pages are hosted on a legitimate-looking domain (`microsoftlogin-secure.com`), but they actually route requests through a C&C server (`93.184.216.34`). This technique makes it challenging for network security tools to identify and block the traffic.

2. **Stealthy Communication:** The phishing pages communicate with the C&C server using encrypted HTTPS connections, making it difficult for network monitoring tools to intercept or analyze the data being exfiltrated.

3. **Dynamic IP Addresses:** The threat actors frequently change the IP addresses associated with their phishing servers to avoid detection by IP-based blocking mechanisms.

**Detection Strategies:**
To mitigate the risk of credential harvesting campaigns, organizations should implement the following strategies:

1. **DNS Security:** Implement DNS security extensions like DNSSEC and DNS over HTTPS (DoH) to ensure that domain names are not being tampered with or redirected.

2. **Network Monitoring:** Use network monitoring tools capable of detecting anomalous traffic patterns, such as unexpected encrypted HTTPS connections originating from internal networks.

3. **Phishing Awareness Training:** Regularly train employees on recognizing phishing attempts and the importance of verifying URLs before entering sensitive information.

4. **Security Gateway Solutions:** Deploy advanced security gateways that can detect domain fronting techniques and other evasion tactics by analyzing traffic patterns and content.

5. **Endpoint Protection:** Use endpoint protection solutions that incorporate heuristics and behavioral analysis to identify suspicious activities, such as the opening of untrusted web pages or the use of unauthorized browser extensions.

**Conclusion:**
The threat actor profiled here utilizes a sophisticated approach to credential harvesting through fake Microsoft 365 login pages. By employing domain fronting and other evasion techniques, these actors are able to bypass traditional security measures. Organizations must adopt a multi-layered defense strategy that includes robust network monitoring, employee training, and advanced security technologies to mitigate the risks associated with such threats.
